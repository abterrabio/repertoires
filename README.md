# repertoires
Antibody repertoire datasets in AIRR-seq format

These are demo datasets for use with the freely available AirrSeqViewer tool, available at [https://abterrabio.com/airrseq-viewer-software/](https://abterrabio.com/airrseq-viewer-software/).


| Dataset | Species | Chain | Notes |
|---|---|---|---|
| [rabbit_hc_component_demo.airr.tsv](./rabbit_hc_component_demo.airr.tsv) | Rabbit | IGH | Single clone cluster |
| [llama_vhh_timeseries.airr.tsv](./llama_vhh_timeseries.airr.tsv) | Llama | IGH | Immunization PBMC time series of HCAbs |
| [human_hc_bulk.airr.tsv](./human_hc_bulk.airr.tsv) | Human | IGH | Human multi-isotype PBMC sample |
